# Third-party dependencies

Dependencies installed from npm retain their own licenses. They are not
relicensed by this repository's MIT License.

Earlier revisions accidentally committed files from `youtube-transcript`
version 1.2.1. Those vendored files have been removed; the dependency's npm
metadata identifies it as MIT-licensed and attributes it to Kakulukian:

- Source: https://github.com/Kakulukian/youtube-transcript
- Package: https://www.npmjs.com/package/youtube-transcript/v/1.2.1

Install dependencies from their lockfiles instead of committing
`node_modules/`.
